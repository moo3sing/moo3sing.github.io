1. 기존에는 오늘을 통째로 제외했다. 11/13 00:28에도 11/13 전체가 빠졌다. 현재 시각부터 12/1 00:00 KST 직전까지 초 단위로 계산하며, 오늘의 잔여 시간과 11/30을 포함한다. 월 배분과 하루 평균도 같은 소수 일수를 사용한다.
2. 후원자 감쇠 예측은 배열 길이로 일수를 세어 소수 부분을 버렸다. 기존 정수 일수의 감쇠 계수는 유지하고 마지막 부분 일수를 비례 반영했다. 11/30 낮에도 후원 증가가 예측되며 마감 시점에 0이 된다.
3. 기존 추세의 실제 평균은 관측 날짜의 일 번호로 나눠 자정에 변했다. 10월은 10/1 00:00부터 해당 지표의 관측 시각까지, 11월은 실제 anchor의 지표별 관측 시각부터 해당 지표의 새 관측까지 경과시간을 사용한다. Oct31 anchor가 자정 확정치가 아니라는 점도 반영한다.

## 추가 확인

- 실제 순위와 점수는 순위형·백분위·1위 대비·Min-Max·Log 모두 수정 전과 같다. 80/10/10, 후보 100명, 순위 예약·고정 후원 가정, raw 8,825,336 / 보정 -70,000 / 적용 8,755,336을 보존했다.
- 모든 시나리오·모델의 solver는 최소 정수 목표에서 TOP70 이내, 목표가 양수이면 1명 적을 때 TOP70 밖인지 검사한다. 0명으로 이미 충족한 경우에는 경계가 꼭 70위일 필요가 없다. 이 경우를 잘못 70위로 고정했던 테스트도 바로잡았다.
- 최근 7일은 원본 증가량과 실제 경과시간을 사용한다. 보정 변경·원본 감소를 성장으로 세지 않고, 미갱신 지표의 관측일을 새 날짜로 바꾸지 않는다. 월별 고유 후원자도 합산하지 않는다.
- 보수적 목표는 띵귤의 낮은 지표 예측·경쟁자의 높은 지표 예측을 적용한 뒤 세 시나리오 목표의 최대치를 사용한다. 정규화로 인해 지표를 모두 높인 경우가 항상 최대 목표가 되지는 않으므로 비교 하한을 유지한다.
- 그래프의 11개 과거 지점과 현재 지점을 새 시간 기준으로 재계산했다. 모델 비교 키를 변경해 이전 시간 모델과 섞이지 않게 했다. 원본 archive는 변경하지 않았다.
