# 메인 추이 그래프

기존 목표·현재 실적·세 모델 카드·월별 목표·안내 문구는 유지하고 그 아래에만 추이를 추가한다. 예측 공식과 가중치는 변경하지 않는다.

- 방송 지표만 사용한다. nginx 접속 IP는 입력으로 사용하지 않는다.
- 원본과 보정값을 보존한다. 현재 비교 구간은 같은 누적 -70,000명 보정과 단츄 후원 가정이 적용된 10/19 23:22부터다.
- 각 관측 당시 저장된 **동일 모델**의 현재·예상 순위를 연결한다. 과거 대표 모델이 순위형에서 Min-Max로 바뀌어도 서로 다른 모델을 하나의 선으로 합치지 않는다.
- 마지막 관측의 모델별 예상 65~75위에서 띵귤을 제외한 명단을 고정한다. 기본 그래프는 각 관측 시점의 실제 연간 누적 유저를 비교한다. 경쟁자 중앙값은 같은 명단의 그 시점 누적값 중앙값이며, 개별 경쟁자를 선택하면 해당 인물의 누적을 직접 표시한다. 현재 명단을 과거에 적용한 비교이므로 당시 경계 명단이었다고 표시하지 않는다.
- 누적 그래프를 0으로 맞추지 않고 실제 값과 그에 맞춘 세로축을 사용한다. 일평균 보기에서는 같은 명단의 개별 증가율 중앙값을 사용한다. 관측 사이 일평균은 실제 경과 시간으로 나눈다. 10/20은 원본 집계 시각 미제공으로 해당 시각에 닿는 일평균 구간을 제외한다. 여러 날의 공백은 평균 구간으로 표시하며, 자료 없는 날에 새 관측값을 생성하지 않는다.
- 선은 관측 사이 연결이며 실제 일별 측정치가 아니다. 시청자 고유 인원이나 방송일 평균으로 해석하지 않는다.
- 후원자는 마지막 연간 고유 확인값과 기존 미래 추정만 사용한다. 월별 고유 후원자를 더하지 않는다. 순위 변화에는 유저 외에 별풍선·후원 추정·남은 기간도 영향을 준다. 그래프를 인과 분해로 표시하지 않는다.

`scripts/trend_history.py`는 이전 전체 관측과 그 시점의 저장된 계산 결과를 `trendHistory`로 압축한다. `manual_batch_update.prepare`와 정상 자동 수집 발행 경로가 이전 관측을 보존하므로 이후 수동 업데이트에서도 누적된다. 새 관측은 사용자가 제공한 원본 시각 메타데이터가 최종 확정된 뒤 화면에서 읽는다. 부분 갱신·실패·재표시는 새 전체 후보 관측으로 만들지 않는다. 과거 파일은 변경하지 않는다.

비교 기준 키는 후보 명단, 잠긴 기준 자료, 최근 추세 입력, 단츄 가정, 계산 버전을 묶는다. 기준이 달라지면 비교 구간을 나눈다. 뷰봇 보정이 바뀌어도 같은 선에 이전 가정을 이어 붙이지 않는다. 과거 값은 저장소에 남긴다.

그래프는 자체 SVG로 그리며 외부 라이브러리·API·접속 분석을 사용하지 않는다. 마우스·터치·좌우 방향키 및 관측값 표를 제공한다. 원래 목표 계산과 별도로 오류를 처리한다.
