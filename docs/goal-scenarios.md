# 목표 시나리오 비교

메인 상단은 왼쪽부터 최근 7일 평균, 기존 추세, 보수적 목표를 표시한다. 모든 값은 현재 보정 누적에서 앞으로 필요한 추가 시청자 수이며, 각각 순위형·1위 대비·Min-Max의 최대 목표를 사용한다. Log는 이 최대값에 포함하지 않는다.

- **최근 7일:** 현재 `recentTrend` 입력과 관측 부족 시 대체 정책을 그대로 사용한다.
- **기존 추세:** snapshot의 새 `recentTrend` 입력만 배제하여 기존 `rollingMetric` 방식으로 매번 재계산한다. 이전에 표시했던 숫자를 고정하는 방식이 아니다.
- **보수적:** 사용자 선택에 따라 시청자·후원자·별풍선 각각의 예상값을 비교하여 띵귤은 최근 7일/기존 추세 중 낮은 값, 경쟁자는 높은 값을 사용한다. 기존 가중치·후원 가정·후원자 체감·기간·동점 처리·TOP70 solver는 동일하다.

정규화 때문에 모든 경쟁자의 원본 예상값을 올려도 합성 시나리오의 최소 목표가 반드시 커지는 것은 아니다. 따라서 오른쪽의 보수적 표시값은 최근 7일·기존·합성 시나리오 목표 중 최대값으로 정한다. 어느 필요한 목표가 산정 불가능하면 보수적 표시도 산정 불가능으로 처리한다. 이는 두 추세 범위 안의 명시적인 가정 비교이며, 모든 미래 상황의 수학적 최악을 찾는 최적화 모델은 아니다.

아래 종합 순위·모델별 결과·추이 및 누적 시청자 100% 참고 목표는 최근 7일 기준을 유지하고 화면에 이를 명시한다. 기존 snapshot, 캐시된 7일 계산 결과, 관측 시각, cohort, 원본 누적 및 보정은 바꾸지 않는다. 세 목표는 화면이 새 자료를 읽을 때 함께 재계산한다.
