# 최근 7일 평균 추세

2026-11-12부터 최신 모델은 지표별 실제 관측 증가량을 최근 7일의 실제 경과시간으로 나눈 평균을 사용한다. 시청자·별풍선 및 확인된 연간 고유 후원자에 같은 방식으로 적용한다. 누적 시청자 80% / 후원자 10% / 별풍선 10%, 후보·제외 규칙, 순위 예외, 기존 TOP70 solver, Log의 SafeTarget 미포함 정책은 유지한다.

## 관측 및 계산

- `scripts/recent_trend.py`가 수동 갱신과 자동 수집의 `calculate_targets` 호출마다 보관된 일별 관측·수동 갱신 전 snapshot과 현재 관측을 읽어 공개용 `recentTrend` 입력을 재생성한다. 원문·인증 정보는 포함하지 않는다. API 요청은 추가하지 않는다.
- 자료 기준 시각부터 과거 7일과 겹치는 관측 간 증가를 실제 시간으로 가중한다. 정확한 경계 관측이 없으면 양쪽 관측 구간의 일정한 평균 속도를 가정해 경계값을 추정한다. 가상의 일별 관측을 생성하지 않는다.
- 간격이 7일을 넘는 두 관측은 연결하지 않는다. 1~7일 미만의 비교 가능한 기록만 있으면 그 기간 평균과 실제 관측 일수를 표시한다. 비교 가능 기간이 1일 미만이거나 최근 관측이 없으면 기존 추세로 대체하고 표시한다.
- 지표별 관측 시각이 같은 값을 중복 계산하지 않는다. 수동 입력에 없는 후원자를 새로 확인한 것으로 취급하지 않는다. 자동 수집이 실제로 재확인한 경우는 수치가 같더라도 새 관측이다. 수집 실패·차단은 관측을 만들지 않는다.
- 띵귤 시청자 증가 속도는 보정 전 원본끼리 비교한다. 순위 계산에는 기존 보정 후 누적을 사용하므로 보정 변경이 성장량으로 오인되지 않는다. 원본 감소가 있으면 그 이후의 비교 가능한 구간부터 다시 시작한다.
- 비공개 후원 후보도 시청자 관측이 충분하면 7일 시청자 추세를 적용한다. 고정 후원 가정은 유지한다. 시청자 전용 참고 목표는 전체 후보의 같은 예상 시청자 값으로 계산하며, 종합 SafeTarget에 포함하지 않는다.
- 후원자 예상 증가의 기존 체감 가정과 12월 1일 예측 종료 정책은 유지한다. 과거·실제 누적, 관측 시각, baseline, 보정 및 원본 이력은 변경하지 않는다.

## 기존 이력

예전 모델의 forecast와 새 모델의 forecast를 같은 구간으로 비교하지 않도록 비교 키를 분리한다. 보관된 전체 후보 snapshot으로 재계산할 수 있는 기존 그래프 관측은 새 모델로 재산정하고, 원본 archive는 보존한다. 부분 관측도 그래프에 포함하되 지표별 관측 시각과 갱신 인원을 유지하여 전체 후보가 새로 실측된 것으로 취급하지 않는다. 미갱신 값은 일평균 산정에서 제외한다.

이 모델은 입력 자료가 갱신될 때 새 7일 구간으로 재계산된다. 웹 화면의 주기적 재조회는 새 원본을 수집하는 기능이 아니며, API 차단·수집 주기 정책을 바꾸지 않는다.
